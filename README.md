# SunriseAI business demos

Batch 1: first five businesses from `uae_saudi_no_website_leads.xlsx`, Leads sheet, in spreadsheet order. Each business folder is a standalone static Vercel project.

## Deploy
Import this GitHub repository into Vercel once per business. Set Root Directory to the corresponding business folder, Framework Preset to Other, and leave Build Command empty. No dependencies or build are needed. Each folder includes vercel.json.

## Local viewing
From this repository run `python -m http.server 8000`, then open a business folder through the local server.

## Owner review
See OWNER-NOTES.md in each folder. Generic service suggestions, hours placeholders and illustrations are explicitly labelled. Listed ratings are historical spreadsheet observations, not live ratings or fabricated reviews. WhatsApp links open a bilingual draft enquiry, never auto-send. A mobile number does not confirm WhatsApp registration. No owner has been contacted.

The footer email belongs to SunriseAI, not the business. Review Arabic transliterations with each owner before final publication.
